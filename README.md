# Ayo Bangun.ID Contractor - Multi File PWA

Paket ini dipisahkan dari full code yang diberikan.
Struktur utama:
- index.html
- manifest.json
- service-worker.js
- styles.css
- src/config.js
- src/firebase.js
- src/services/*
- src/views/*

Sebelum deploy:
1. Isi Firebase config.
2. Aktifkan Firebase Authentication Email/Password.
3. Aktifkan Realtime Database.
4. Tambahkan logo-ayo-bangun.jpeg pada assets/.
